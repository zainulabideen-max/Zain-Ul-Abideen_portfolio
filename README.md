# Zain-ul-Abideen — Portfolio

A responsive, multi-page portfolio with a green cyber/neon visual theme and three self-contained browser demos.

## Pages
- `index.html` — Home
- `about.html` — About, education and skills
- `projects.html` — Project showcase
- `contact.html` — Email and LinkedIn contact

## Interactive demos
- `projects/studyflow/index.html` — study task planner (browser LocalStorage)
- `projects/spendwise/index.html` — expense tracker (browser LocalStorage)
- `projects/weatherx/index.html` — live weather lookup (Open-Meteo API; internet required)

## Preview locally
Open `index.html` in a modern browser. The StudyFlow and SpendWise demos work locally. WeatherX needs an internet connection.

## Publish with GitHub Pages
1. Create a **public** repository (or use the existing repository) and upload the *contents* of this folder, not the enclosing `zain_portfolio` folder.
2. Ensure `index.html` is in the repository root alongside `about.html`, `projects.html` and `contact.html`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the Pages deployment to finish. The root site and project demo links will then resolve from the deployed URL.

## Notes
- No professional experience section is included.
- Contact form opens a pre-filled email draft; it does not send or store messages itself.
- StudyFlow and SpendWise store data only in the visitor's browser. Clearing browser data removes those saved entries.
- WeatherX uses the public Open-Meteo geocoding and forecast endpoints and requires internet access.
- Review, understand and personalize the projects before presenting them as your own work. The demos are included as working portfolio examples, not proof of authorship.
